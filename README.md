# Contact Form Website

This is a simple and modern contact form website built with HTML and CSS.

## 🚀 Features
- Clean and responsive design
- Contact form with name, email, and message
- Connected to Formspree for email handling

## 🛠️ Technologies Used
- HTML
- CSS

## 🌍 Live Demo
https://paakwesitechie-art.github.io/veli/

## 📩 How It Works
Users can fill out the form and send messages, which are delivered directly to my email using Formspree.
